\# Chatbot Using Deep Learning



\## Project Overview



This project implements a chatbot that processes user messages and generates responses based on predefined intents and responses.



The project includes a trained model, an intent configuration file, saved word and class mappings, and Python scripts for chatbot functionality and its graphical user interface.



\## Features



\- Intent-based chatbot interaction

\- Intent definitions and responses stored in JSON

\- Trained model for predicting user intents

\- Saved vocabulary and intent-class mappings

\- Python-based chatbot interface



\## Technologies Used



\- Python

\- TensorFlow / Keras

\- NumPy

\- JSON

\- Pickle

\- Additional libraries as required by the implementation



Verify the imports in the Python files and retain only the technologies actually used.



\## Project Structure



```text

Chatbot-Project/

├── main.py

├── Gui1.py

├── intents.json

├── chatbot\_model.h5

├── words.pkl

├── classes.pkl

├── requirements.txt

├── .gitignore

└── README.md

```



\## Getting Started



\### 1. Clone the repository



```bash

git clone https://github.com/Amrutha-V-L3/Chatbot-Project.git

cd Chatbot-Project

```



\### 2. Create a virtual environment



```bash

python -m venv .venv

```



On Windows:



```cmd

.venv\\Scripts\\activate

```



\### 3. Install dependencies



```bash

pip install -r requirements.txt

```



\### 4. Run the chatbot



Start with the command corresponding to the interface you want to use:



```bash

python main.py

```



For the graphical interface, try:



```bash

python Gui1.py

```



The correct entry point and required setup should be confirmed from the source code.



\## Model and Data Files



The repository includes the trained model and supporting vocabulary and class files used by the implementation. Keep these files consistent with the code that loads them.



\## Limitations



Chatbot responses depend on the available intents, training data, and model. It may not correctly answer questions outside its trained intent categories.



\## Future Improvements



\- Expand the range of supported intents.

\- Improve handling of unfamiliar user messages.

\- Add a broader evaluation of intent classification.

\- Improve the user interface and conversation experience.
